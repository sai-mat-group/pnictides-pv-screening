# Pnictides for photovoltaic applications

This repository contains data from density functional theory based calculations that are presented as part of the manuscript, "Extending the Pnictide Chemical Space for Photovoltaics" that is currently under review. A pre-print of the manuscript is currently available on [arXiv](http://arxiv.org/abs/2608.30402).

The structure of the folders are self-explanatory, with A4BX2, ABCX2, and BBBX2 representing different pnictide classes. While all folders contain results from structure relaxation runs, there are files associated with electronic density of states, electronic band structure, phonon force constants, and defect calculations for select compositions, as describe in the manuscript.

In case you use the data presented in this repository or in our manuscript, we will appreciate a citation to our work at [arXiv](http://arxiv.org/abs/2608.30402).
